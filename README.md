# Frontline passive fire app

Offline-first phone app for scouting and completing passive fire penetrations.

- The app files sit at the top of this repo and are served by GitHub Pages.
- `apps-script/Code.gs` is the backend, pasted into the Passive Fire Master Google Sheet (Extensions > Apps Script).

No data, prices or keys live in this repo. Each device connects with a setup code made by `addUser` in the Apps Script editor.
